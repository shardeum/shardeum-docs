# Run an RPC Node

Learn how to set up and run an RPC node on Shardeum network.

## What is an RPC Node?

RPC (Remote Procedure Call) nodes provide API endpoints for applications to interact with the Shardeum blockchain. They serve as the gateway for dApps and wallets.

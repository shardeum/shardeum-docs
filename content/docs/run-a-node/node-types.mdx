# Node Types

Learn about the different types of nodes you can run on Shardeum network.

## Overview

Shardeum supports multiple node types, each serving different purposes in the network:

- **Full Nodes**: Store complete blockchain data and validate transactions
- **Validator Nodes**: Participate in consensus and earn rewards
- **RPC Nodes**: Provide API endpoints for applications to interact with the network

Choose the node type that best fits your needs and technical requirements.

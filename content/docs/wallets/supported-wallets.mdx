## MetaMask

MetaMask is a self-custodial wallet for EVM-compatible networks, available as a browser extension and mobile app. It allows users to manage digital assets, connect to dApps, and interact with Shardeum and other EVM networks.

https://metamask.io/

## Are other wallets supported?

Any wallet that follows the MetaMask RPC API specification and enables adding custom EVM networks will work with Shardeum.

https://docs.metamask.io/guide/rpc-api.html#table-of-contents

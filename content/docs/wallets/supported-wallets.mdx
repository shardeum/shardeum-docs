## MetaMask

MetaMask is a self-custodial wallet extension for EVM chains. 
A safe and simple way to access blockchain applications and web3. Trusted by millions of users worldwide.

https://metamask.io/

## Keplr

Keplr is a self-custodial wallet that supports both EVM networks and advanced staking features. You can already use Keplr to hold SHM and connect to Shardeum’s EVM mainnet. As Shardeum introduces staking, delegation, validator management, and governance, Keplr will support these features because it natively integrates the modules used for staking operations.

https://www.keplr.app/

## Are other wallets supported?

Any wallet that follows the MetaMask RPC API specification and enables adding custom EVM networks will work with Shardeum.

https://docs.metamask.io/guide/rpc-api.html#table-of-contents

## Disclaimer

Shardeum is fully compatible with EVM standards. MetaMask is sufficient for core transactions and dApp interactions, while Keplr will offer the most complete experience for staking and validator-related functionality. Always use official sources to download wallets and verify network details.

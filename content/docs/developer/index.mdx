# Building on Shardeum

Welcome to the Shardeum Developer Hub. This section provides comprehensive resources, documentation, and guides to help you build decentralized applications on Shardeum's scalable, EVM-compatible blockchain.

## Why Build on Shardeum?

- **EVM Compatibility**: Deploy existing Ethereum smart contracts with minimal to no changes
- **Low Transaction Fees**: Shardeum's dynamic state sharding keeps fees low even as network usage grows
- **Linear Scalability**: Transaction throughput increases as more nodes join the network
- **Atomic Composability**: Cross-shard transactions maintain composability, enabling complex DeFi applications
- **True Decentralization**: Low hardware requirements allow for broad validator participation

### JSON-RPC API

Shardeum provides a comprehensive JSON-RPC API that is fully compatible with Ethereum's API. This allows developers to use familiar tools and libraries like Web3.js, Ethers.js, and Hardhat to interact with the Shardeum network. The API documentation covers all available methods for querying blockchain data, submitting transactions, and interacting with smart contracts.

## Getting Started

1. **Connect to Shardeum**: Configure your development environment to connect to Shardeum's testnet or mainnet
2. **Set Up Your Wallet**: Add Shardeum to your wallet and obtain test tokens from the faucet
3. **Deploy Your First Contract**: Use familiar development tools to deploy and test your smart contracts
4. **Interact with the Network**: Leverage Shardeum's JSON-RPC API to build your dApp's frontend
